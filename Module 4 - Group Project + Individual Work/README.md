# Farm Store Management System

## User Story

You have inherited a family farm from your beloved aunt and uncle who tragically passed away in a car accident. The 10-acre farm includes:
- A house
- Animals
- A store selling farm-related products (similar to PetSmart or Tractor Supply)

Your aunt and uncle ran the business "old school" using only pencil and paper. You've decided to take over the business and modernize it by developing a computer program to manage operations.

## Business Requirements

The farm store management system needs to handle:

### 1. Store Inventory
- Track items sold through the store
- Manage product inventory

### 2. Service Management
- Schedule services offered (e.g., basic veterinary services)
- Track services provided
- Record payments received

### 3. Animal Sales
- Manage sales of farm animals including:
  - Ducks
  - Chickens
  - Hamsters
  - Rabbits
  - Other farm-related animals
- Support occasional specialty animal resales from local breeders

## Technical Requirements

### Programming Specifications
- **Language:** Java
- **Interface:** GUI-based program using JOptionPane or another graphical approach

### Code Structure
- Use **classes** where appropriate to encourage code reuse
- Include **methods** for organizing functionality
- Implement **decision structures** for handling business logic
- Present information in a **clear and user-friendly GUI format**

## Project Approach

This is a **group project**. Work with your team to:
1. Create a preliminary plan for organizing business tasks
2. Design the program architecture
3. Implement the Java GUI solution
4. Test and refine the user experience

*This project combines object-oriented programming principles with practical business management needs.*
