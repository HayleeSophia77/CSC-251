# CSC-251, Adv. Java
After this course, the student must be able to demonstrate, with at least 70% accuracy, the following:

Applied logic to develop problem-solving algorithms, created JAVA source code to solve specific information system requirements, documented program source code clearly and concisely, compiled, debugged, and executed GUI-based JAVA programs. 

Module_2 ~ Individual Project must be completed using Visual Studio Code that was introduced in Module_1. The Project must be completed (and submitted) using JAVA, not Python, or C++, or any other programming language available in Visual Studio Code. The Project must be completed using GUI features, such as the JOptionPane showMessageDialog and the showInputDialog boxes. The Project is expected to be completed using AI as a resource, do the time constraints of the project.

Module_2 ~ Individual Project files are expected to be correctly named and submitted, as well as uploaded to the student's GitHub repository created for this class, including ALL of the following:

1. JAVA Code
2. Screenshots of Code and Output
3. AI Prompts
4. AI Generated Code
5. Any other required or relevant materials
