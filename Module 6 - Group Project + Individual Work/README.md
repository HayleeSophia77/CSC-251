# Farm Store Manager (CSC-251 Group Project)

A multi-file Java Swing application to manage a small farm store: inventory, animal sales, services/appointments, employees/time tracking, and reports.

## Project Overview

This application provides comprehensive management tools for a small farm store business, including:

- **Inventory Management** - Track items sold through the store
- **Animal Sales** - Manage farm animals (ducks, chickens, hamsters, rabbits, etc.)
- **Service Scheduling** - Schedule and track veterinary and other services
- **Employee Management** - Track employee information and time entries
- **Appointment System** - Manage customer appointments
- **Reports & Analytics** - Generate business reports and insights

## Technologies Used

- Java
- Java Swing (GUI)
- Maven (Build tool)
- CSV file storage
